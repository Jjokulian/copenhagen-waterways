# I3 — Changing sampling frequency and season

**Claim (HYPOTHESES.md).** "A deficit indicator built from the worst month is biased by
how often you sampled that month. More visits find more extremes." Outcome O1.

Neighbour I1 asks *which stations*. This asks *how often, and when in the year* — temporal
aliasing of a quantity that varies faster than the sampling interval.

## The hypothesis splits in two, and only one half is scoreable

**I3a — count and window.** An extremal indicator (annual minimum, worst-month value,
days-below-threshold) is a first-order statistic. Its expectation moves with the number of
draws and with which months the draws fall in. Testable in full.

**I3b — diel phase.** Oxygen has a diel cycle; daylight at 55°N runs ~7 h (December) to
~17 h (June), so working-hours sampling walks the diel phase with season. **There is no
time-of-day column anywhere in the archive.** Verified across all four ODA exports:
`ctd.csv.gz` (34 fields), `lys.csv.gz` (30), `maaledybde.csv.gz` (19), `stations.csv` (17)
— every temporal field is `YYYYMMDD`. Class 6, absent dimension: not recoverable, not
boundable, not countable. I3b is **unscoreable, not unsupported**, and no result below
speaks to it. Nothing here licenses a claim that the diel confound is absent or small.

## Observable consequence (I3a), stated to be falsified

If I3a is right, an extremal severity indicator computed under **fixed effort and a fixed
calendar window** will show a different temporal pattern than the same indicator computed
on whatever visits each station-year happens to contain. If the two paths coincide inside
the resampling envelope, I3a is refuted as an explanation of the O1 trend.

Two directions must be separated, because they push opposite ways and the data show they
nearly cancel:

- **Count.** More draws, lower minimum, mechanically.
- **Window.** Sparse programmes are not thin versions of dense ones — they are
  late-summer-targeted. Station-years with ≤3 near-bed oxygen months put 50.2% of their
  observations in August–September; station-years with ≥9 months are near-flat (7.2%–8.8%
  per month). Sparse sampling therefore *finds* hypoxia while having few chances to.

## The null under the constraint I impose

**Constraint:** station-years with all twelve calendar months present — **2,314** of 11,289.
Effort is fixed at 12 and station composition is fixed inside each unit, so nothing is
compared across differently-observed units.

**The null is computed, not assumed, and the naive one is wrong.** Marginally, minima do
*not* fall with visit count: median annual minimum is 4.73 mg/l at 3 visits and 6.30 at 12.
A null of "severity rises with count" would be inverted by the window effect. Within the
2,314 fixed units, drawing month-sets from each station-year's own twelve values (200 Monte
Carlo draws):

| indicator on the same 2,314 station-years | mean min (mg/l) | P(min < 4) |
|---|---|---|
| min over all 12 months | 5.69 | 0.250 |
| E[min over 3 months drawn at random] | 7.23 | 0.058 |
| min over the fixed window {Jul, Aug, Sep} | 5.93 | 0.219 |

Count alone moves exceedance by **4.3×**; fixing the window to Jul–Sep recovers almost all
of the 12-month signal from 3 draws. That table *is* the null: the per-station-year
resampling distribution of the indicator, against which any observed path is scored.

## Procedure

1. Build the effort-matched panel: station-years containing all of Jul, Aug and Sep —
   **6,802** units; **8,771** have ≥2 of the three. 323 stations carry ≥10 such years,
   225 carry ≥15, spanning 1980–2026 (789/2,411/2,006/1,697/1,091 by decade band).
2. Compute the severity indicator twice per station-year: (a) on all available months,
   (b) on exactly {Jul, Aug, Sep}. Never aggregate to water bodies; the unit is the station.
3. For each unit, draw 200 month-sets of the same size from that unit's own values to get
   the null envelope for (a). Score the observed path of (a) against it.
4. Regress each indicator on year with station fixed effects. Compare slopes and the year-
   to-year path of (a) and (b).
5. Repeat with the Aug–Sep window and with a 2-of-3 window, as sensitivity.

## What a result would and would not license

**Would.** If (b) is flat where (a) trends, or the slopes differ beyond the envelope, then
the O1 severity trend is partly a trend in sampling design, and every extremal indicator in
this project must be recomputed effort-matched. If (a) and (b) agree, I3a is falsified for
extremal indicators at monthly resolution — a real result, and the stronger one.

**Would not.** It says nothing about (i) I3b, the diel confound, which stays unscoreable;
(ii) sub-monthly variance, which needs the raw daily file, not this panel; (iii) *rate*
indicators, already shown robust to effort and station composition here — this test is
about extremal statistics only, where the count dependence is structural; (iv) which
stations were observed, which is I1's.
