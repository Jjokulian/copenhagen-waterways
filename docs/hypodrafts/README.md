# Hypothesis test drafts

One file per hypothesis that **can** be tested with data that exists. Each states the
observable consequence, the data source with its error class, the null **under the
constraint actually imposed**, and what result would falsify it.

A draft is not a result. Nothing here has been run.

Companion: [`../openproblems/`](../openproblems/) holds the hypotheses that cannot be
tested yet, each classified by what is missing.
