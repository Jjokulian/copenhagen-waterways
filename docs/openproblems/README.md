# Hypotheses that cannot be tested yet

One file per hypothesis, classified by what is missing:

- **experiment** — needs an intervention, constructive or investigative
- **measurement** — needs a quantity nobody records, or a new metric over what is recorded
- **armchair** — solvable by connecting existing data, but too large for an autonomous
  background agent. **Tentative, not an obstacle.**

The distinction matters: a hypothesis marked *measurement* is unscoreable, not refuted.
An absent dimension is not evidence of absence.
