# If you have data access we don't

## The three states, of which this page is one

Every input this project could use is in one of three states, and the
system is written for all three rather than for the one it happens to have.
That ordering matters: an analysis written against the data on hand is worth
only what that data is worth, but an analysis written against a stated
contract runs on whatever arrives, and says what it could not do.

| state | meaning | where it lives |
|---|---|---|
| **wanted** | nobody has measured it, anywhere. The measurement has to be invented or funded before the question is answerable at all. | [EXPERIMENTS.md](EXPERIMENTS.md), and the 40 hypotheses marked *unscoreable* in [hypodrafts/TRIAGE.md](hypodrafts/TRIAGE.md) |
| **gated** | it exists, someone holds it, and this project cannot reach it. | **this page** |
| **held** | on disk, with whatever faults it has. | everything else on this site, and the fault list in [DATA_SOURCES.md](DATA_SOURCES.md) |

**What is published here is the degraded run of a system built for the
first column.** That is the claim worth arguing with. Not *this is what the
open data supports* - which invites the reply that the data is poor and the
conclusions are therefore soft - but *this is the analysis, here is the
contract it consumes, and here is what it currently has to eat.* Hand it
better input and the same code produces a better answer without anyone
rewriting an argument. Where the answer would change, it changes in public.

The pattern is not aspirational. Section 2c of [NITROGEN.md](NITROGEN.md)
had been written for months and rendered nothing, because the file it needed
did not exist; the day that file was first produced, the section appeared
with its numbers in it and no prose was written to make that happen.

This project is run from open data by someone with no institutional
credentials. A large part of what it cannot answer is not hard - it is
**gated**. If you hold a utility login, a field sheet, a drainage archive or a
service agreement, you can unblock in an afternoon what this cannot unblock at
all.

**You do not have to write any code, and you do not have to send anything to
anyone.** Clone the repository, put your file in `data/dropin/` under the name
given below, and run:

```sh
python3 scripts/unlock.py          # validates it, then runs what it unblocks
```

The file stays on your machine. Nothing is uploaded. What changes is that the
pages regenerate with your data in them, and you can see whether it moves any
conclusion - which is the only thing worth knowing.

**Do not send anything you would be breaking a licence or an agreement to
send, and do not send personal data.** LER, the cable and pipe register, is
excluded on purpose and stays excluded: it is provisioned for excavation
safety and this project has no excavation to be safe about. A slot you cannot
fill without breaching something should stay empty. The gap is a finding.

## 1. Slots — hand these in mechanically

Each of these has a fixed filename and a fixed shape, so the analysis can be
written against it before anyone has it.

### `overflow_measured.csv` — SPILDEVANDSDATA

**Unlocks.** Overflow as a measurement rather than a model. Every overflow figure on this site is a registered or modelled volume; none has been compared with a metered one.

**Shape.** `one row per overflow event: outfall_id;lon;lat;start;end;volume_m3;rain_mm  (semicolon or comma, header required, ISO timestamps)`

**Who plausibly holds it.** HOFOR, BIOFOS and other utilities; Miljoestyrelsen through PULS

*No script consumes this yet.* The slot exists so the data can arrive
before the analysis is written - the shape is fixed in advance so the
analysis can be written against something real rather than imagined.

### `puls_pointsources.csv` — PULS

**Unlocks.** Point-source load beside the diffuse residual, at the resolution the residual is computed against.

**Shape.** `one row per point source per year: cvr;name;lon;lat;year;n_kg;p_kg;bod_kg;type`

**Who plausibly holds it.** Miljoestyrelsen

**Hypotheses waiting on it.** B1 B2 B3 A4 B5 E5

*No script consumes this yet.* The slot exists so the data can arrive
before the analysis is written - the shape is fixed in advance so the
analysis can be written against something real rather than imagined.

### `draenede_arealer.tif` — DK-DRAENKORT-AU

**Unlocks.** The surface-versus-drain routing fraction as a mapped quantity instead of a single national dial. Tile-drained land bypasses the riparian zone and most of the denitrification, so this is the term between field surplus and delivered load.

**Shape.** `GeoTIFF, EPSG:25832, one band, drained=1 / not=0 or a probability in 0-1. The published product is 30.4 m.`

**Who plausibly holds it.** Aarhus Universitet DCA; Miljoestyrelsen; Danmarks Arealinformation

**Hypotheses waiting on it.** S1 S6

*No script consumes this yet.* The slot exists so the data can arrive
before the analysis is written - the shape is fixed in advance so the
analysis can be written against something real rather than imagined.

### `cvr_bulk.jsonl` — CVR-BULK

**Unlocks.** Turning a CVR number into who and where, for the manure surplus join. The sibling project danish-livestock holds a 14,222-row subset; the bulk register would complete it.

**Shape.** `one JSON object per line, must carry cvr and one of {name, industrycode, kommune}`

**Who plausibly holds it.** Erhvervsstyrelsen agreement, or a working Datafordeler subscription

*No script consumes this yet.* The slot exists so the data can arrive
before the analysis is written - the shape is fixed in advance so the
analysis can be written against something real rather than imagined.

### `oda_mfs_biota.csv` — ODA-MFS-FISK

**Unlocks.** Marine toxicant loading, currently unscoreable: 7 hypotheses turn on whether contaminants rather than nutrients gate recovery.

**Shape.** `the ODA extract as downloaded - semicolon separated, ISO-8859-1, Parameter and Enhed columns preserved`

**Who plausibly holds it.** anyone with an ODA login and the MFS topics enabled

**Hypotheses waiting on it.** E9 E7 E10 F5

*No script consumes this yet.* The slot exists so the data can arrive
before the analysis is written - the shape is fixed in advance so the
analysis can be written against something real rather than imagined.

### `ctd_visit_times.csv` — FIELD-SHEETS-CLOCK

**Unlocks.** A clock on oxygen AT DEPTH. The water-chemistry topic carries a time on every row and CTD carries none, so 53.7M profile measurements have a date and no hour. 80% of CTD station-days can borrow a time from a same-day bottle; the field sheets would settle the rest and check that borrowing.

**Shape.** `station;date;time_utc  - one row per cast`

**Who plausibly holds it.** DCE, or whoever holds the original cruise logs

*No script consumes this yet.* The slot exists so the data can arrive
before the analysis is written - the shape is fixed in advance so the
analysis can be written against something real rather than imagined.
