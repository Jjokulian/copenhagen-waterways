the last loose end

The field log needs a secure origin. Browsers only give a page your location over HTTPS or on localhost — so on a phone it works from this site, but not from a laptop's http://192.168.x.x.

Reproduce it

  • Standard-library Python 3 and a browser. No dependencies, no API keys, nothing authenticated.
  • ./run.sh fetches 28 GIS layers, crawls the plan, recovers the flood sheets, and rebuilds every figure on this site.
  • Re-running is cheap — every fetch step caches, and the crawl is deliberately slow-paced against a municipal server.
