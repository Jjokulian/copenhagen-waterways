# Drop-in slots

Put a file here under the name `scripts/unlock.py --list` gives, then run:

```sh
python3 scripts/unlock.py
```

It validates the shape, runs whatever was waiting on it, and regenerates
`docs/IF_YOU_HAVE_THE_DATA.md`. **The file stays on your machine.** Nothing is
uploaded and nothing is committed — this directory is gitignored apart from this
README, on purpose, so that a licensed dataset cannot be pushed by accident.

Do not put anything here that you would be breaking a licence or an agreement to
share, and no personal data. A slot you cannot fill without breaching something
should stay empty: the gap is a finding, and the page says so.
